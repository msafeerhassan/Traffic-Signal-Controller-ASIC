## How it works

So being a simple traffic signal controller, it has 6 possible states for the traffic signal. To sum up, either the North-South Lane will have green signal or the East-West lane will have. Green Signal stays up for 5 seconds, yellow signals stays up for 3 seconds while red stays up for 1 seconds. For 1 second, both signals remain red for safety.

## How to test

Simply, run `py run_test.py` in OSS and it will test all use cases and show the final report.
